# 🤖 AI Voice Sales Agent (N8N + AmoCRM + Vapi)

**Прототип голосового помощника для записи на консультацию.**

В репозитории собраны сценарии n8n и материалы по интеграции голосового интерфейса с amoCRM. Это отдельный прототип, а не исходный код текущего веб-демо на сайте-портфолио.

## Статус и границы

Проект не представлен как подтвержденное коммерческое внедрение. Подтверждающие замеры роста конверсии, экономии времени и замены сотрудников в описании не приведены, поэтому такие результаты не заявляются.

Перед использованием сценариев нужны настройка доступов, проверка актуальных API и тестирование на отдельном стенде. Наличие схемы интеграции не подтверждает создание реальной записи или сделки.

Актуальные демонстрации: [портфолио Руслана Зайнуллина](https://ruslanzaynullin.ru/).

## ⚙️ Архитектура системы

Сценарии построены в **n8n**. Предусмотренный маршрут: входящий вебхук голосового сервиса, обработка запроса, обращение к amoCRM и ответ в голосовой интерфейс. Работоспособность маршрута зависит от настройки и проверки внешних сервисов.

### Основные компоненты:
1. **n8n (Оркестрация)**: `Dental AI Agent → AmoCRM.json` - главный обработчик.
2. **Анализ расписания**: `check_availability_workflow.json` - модуль проверки времени врачей.
3. **Голосовой канал**: Vapi (Speech-to-Text & Text-to-Speech) + ElevenLabs для ультра-реалистичного звука.
4. **CRM**: AmoCRM API.
